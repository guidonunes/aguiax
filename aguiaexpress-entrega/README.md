# AguiaExpress

## Como executar o backend
1. Acessar a pasta `backend`
2. Configurar banco de dados conforme `application.properties`
3. Executar a aplicação Spring Boot

## Como executar o frontend
1. Abrir a pasta `frontend` no Android Studio
2. Garantir que a API esteja rodando em `http://10.0.2.2:8080/`
3. Rodar o app no emulador Android

## APK
O arquivo `aguiaexpress.apk` está incluído na raiz da entrega.
